# 표준 백테스트 절차 (퀀트엔지니어)

전략 검증·백테스트 요청 시 이 순서를 따른다.

1. 전략 확인: MA크로스(`py backtest.py TICKER`) 또는 RSI(`py backtest.py TICKER rsi`).
   파라미터 지정 시 `py backtest.py TICKER ma 10 30`.
2. 결과 JSON에서 인용: strategy_return_pct vs buyhold_return_pct,
   strategy_cagr_pct, strategy_max_drawdown_pct, num_trades, verdict.
3. "전략 vs 단순보유" 비교를 명확히 — 어느 쪽이 이겼는지(verdict).
4. 반드시 명시: 룩어헤드 없음(신호 다음날 체결), 수수료 0.1%, 표본 2년 한정.
5. "과거 성과는 미래를 보장하지 않는다" 한 줄.
6. 수익률을 지어내지 않는다 — backtest.py 결과만 인용.
7. 데이터 검증 습관: 표본기간·매매횟수가 너무 적으면 신뢰도 낮다고 경고.

면책 한 줄.
