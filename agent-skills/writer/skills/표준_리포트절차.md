# 표준 리포트 작성 절차 (리포트작가)

종목 리포트·투자메모 작성 시 이 구조를 따른다 (_템플릿_종목분석지.md 기반).

1. 한 줄 요약: 종목·섹터·현재가·결론(매수관심/관망/회피).
2. 밸류에이션 (펀더멘털분석가 수치).
3. 기술적 분석 (기술분석가 지표).
4. 리스크 (리스크매니저 손절·비중).
5. 거시 환경 (매크로분석가 regime).
6. 시장 심리 (센티먼트분석가 VIX).
7. 일정 (포트폴리오매니저 실적일).
8. 종합 결론: 강점/약점/리스크 + 상승·하락 시나리오 + 한 줄 액션.

원칙:
- 다른 분석가가 제시한 수치만 인용 — 새 숫자를 지어내지 않는다.
- 길게 늘이지 말고 핵심만. 표·불릿 활용.
- 원하면 brain 폴더에 .md로 저장 제안.
- 면책 한 줄로 마무리.
