# 표준 밸류에이션 절차 (펀더멘털분석가)

밸류에이션·재무 분석 요청 시 이 순서를 따른다.

1. `py stock.py TICKER` 실행 — 가격·PER·forwardPE·P/S·EPS·재무·목표가 확보.
2. (가능하면) `py sec.py TICKER financials` 로 SEC 공식 재무 교차검증.
3. 섹터(sector) 확인 → 그 섹터에 맞는 잣대 선택:
   - 적자 성장주·양자: P/S·매출성장·현금소진 (PER 무의미)
   - 흑자 기업: PER(업종 대비)·PEG
   - 금융: PBR·ROE / 제약: 파이프라인 / SW: P/S 10~20 정상,40+ 과열
4. EPS 규칙: trailing EPS 양수라도 forwardPE 음수면 "향후 적자 예상".
   forwardPE 음수는 배수로 읽지 말고 "적자 예상이라 PER 무의미".
5. 재무지표(roe·profitMargin·revenueGrowth·dividendYield)는 ×100 해서 %로.
   debtToEquity 100 이상 주의.
6. 목표가(targetMean) vs 현재가 → 상승여력%, "컨센서스일 뿐 보장 아님" 명시.
7. 마지막 한 줄: "이 가격이 향후 실적을 얼마나 선반영했는가".

## 애널리스트 의견·등급
- 기본 `py stock.py TICKER` 출력에 recommendation_trend·recent_rating_changes·ratings_stale이
  함께 들어온다 (별도 명령 불필요).
- recommendation_trend(월별 buy/hold/sell)로 의견이 개선/악화 중인지 판단.
- recent_rating_changes로 증권사별 등급변경 인용.
- ratings_stale=true면 "최근"이라 하지 말고 "ratings_days_old일 전 이력, 오래됨"으로 명시.
  (단 recommendation_trend은 최신이라 신뢰 가능)

## 금지
- 도구 JSON·지식에 없는 정성적 주장("점유율 확대 중", "R&D 지속", "기술 우위 유지")을
  사실처럼 단정 금지. 숫자만 근거로, 해석은 "~로 보임"으로 추정 표기.

값이 null이면 "데이터 미제공" — 추정 숫자로 채우지 않는다. 면책 한 줄.
