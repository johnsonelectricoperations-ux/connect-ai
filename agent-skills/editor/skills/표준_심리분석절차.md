# 표준 시장심리 분석 절차 (센티먼트분석가)

시장 심리·공포탐욕 요청 시 이 순서를 따른다.

1. `py macro.py ^VIX` (또는 `py macro.py`) 실행 — VIX 실데이터 확보.
2. 한 줄 진단: "지금 시장은 [공포/중립/탐욕] 국면".
3. VIX 해석: <13 안일·과열, 13~20 평온, 20~30 경계, 30+ 공포(역발상 매수 단서).
4. 공포탐욕지수 정확값을 모르면 지어내지 말고 "확인 필요" + VIX로 대용.
5. 역발상 관점: "공포=즉시 바닥"으로 단정하지 말고 분할 접근 권유.
6. 심리는 보조지표 — 펀더멘털·기술과 함께 봐야 하며 단독 매매신호로 쓰지 않음.

## 애널리스트 컨센서스 (개별 종목 심리)
- 특정 종목의 "월가 의견"을 물으면 `py stock.py TICKER analyst` 실행.
- recent_rating_changes: 최근 어느 증권사가 등급을 올렸나/내렸나(firm/action/from/to).
- recommendation_trend: 월별 buy/hold/sell 분포 변화 — 의견이 개선/악화 추세인지.
- consensus.upside_pct: 평균 목표가 대비 상승여력.
- 데이터가 빈 배열이면 "커버리지 없음/확인 불가"로 답하고 지어내지 말 것.
- 컨센서스는 후행·군집되기 쉬움 → 역발상 관점도 함께. 매수신호로 단정 금지.
