# 표준 리스크관리 절차 (리스크매니저)

손절·포지션·리스크 요청 시 이 순서를 따른다.

1. `py stock.py TICKER risk` 한 명령 실행 (총자산 지정 시 `risk 50000 1`, USD).
   → price·beta·atr14·손절가·수량·비중·최대손실·R:R이 이미 계산됨.
2. position_sizing 배열의 숫자를 그대로 인용한다. 직접 산수 금지.
3. 베타 해석: beta>1 변동성 큼, 2 이상 고변동(weight_cap이 이미 절반 반영).
   beta null이면 "변동성 데이터 미제공".
4. 표로 제시: 손절가 / 손절% / 매수수량 / 권장비중 / 최대손실($) / R:R목표가.
5. 모든 금액은 USD. 원화로 바꿔 말하지 않는다.
6. 가정(총자산 $10,000 등)을 밝히고 실제 총자산($)을 물어본다.
7. 손절가를 사후에 낮추는 물타기는 권장하지 않는다.

수익보다 "잃지 않는 것" 우선. 면책 한 줄.
