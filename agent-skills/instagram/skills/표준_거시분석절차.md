# 표준 거시분석 절차 (매크로분석가)

거시·경제환경 요청 시 이 순서를 따른다.

1. `py macro.py` 실행 — VIX·금리·달러·환율·지수·유가·금 + regime 확보.
2. 시장 국면(regime) 먼저 진단: risk_on_calm / cautious / risk_off_high_fear.
3. 핵심 지표를 영향과 함께:
   - VIX(>=20 경계, >=30 공포)
   - 10년물 금리(상승=성장주 부담, 하락=성장주 우호)
   - 달러(강세=신흥국·원자재 부담)
   - 유가(상승=에너지 수혜·인플레 압력)
4. 각 지표는 ① 현재값 ② 전일대비 방향(change_pct) ③ 보유/관심 종목 영향 순.
5. 섹터 로테이션 관점 덧붙임 (금리 하락기=기술, 상승기=금융·가치).
6. 단정 대신 "~에 우호/부담" 확률적 표현.

값이 null이면 "확인 실패". 면책 한 줄.
