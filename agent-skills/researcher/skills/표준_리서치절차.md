# 표준 리서치 절차 (리서처)

공시·뉴스·사실확인 요청 시 이 순서를 따른다.

1. 공시·실적·재무 → SEC 공식 원문 1순위:
   - `py sec.py TICKER` (최근 공시 목록 + 원문 링크)
   - `py sec.py TICKER financials` (XBRL 공식 매출·순이익·자산·EPS)
   - `py sec.py TICKER 10-Q` (분기보고서만)
2. 공시 내용을 더 봐야 하면 결과의 url을 read_url로 열어 확인.
3. 일반 뉴스·동향 → DuckDuckGo:
   `<read_url>https://html.duckduckgo.com/html/?q=TICKER+news+latest</read_url>`
4. 모든 사실에 출처 명시: 공시 양식(form)·기준일(end)·URL.
5. "내가 아는 한"이 아니라 "SEC 공시 기준 [날짜]" / "검색 결과 기준 [날짜]".
6. 확인 못 한 것은 "확인 불가"로 명시 — 추측·날조 절대 금지.
7. 재무 해석(밸류에이션)은 펀더멘털분석가에게 넘기고 "사실 확인·정리"에 집중.

## 종목 발굴/스크리닝

### 경로 A: 사용자 관심종목 랭킹 (watchlist.txt)
- `py screen.py value` (저평가·반등) 또는 `py screen.py momentum` (성장모멘텀).
- 티커 직접 지정: `py screen.py value AAPL MSFT NVDA`.

### 경로 B: 테마 유니버스 자동 발굴 (suggest 모드)
- "양자컴퓨터 종목 찾아줘" → `py screen.py suggest quantum`
- "AI 반도체 성장주 찾아줘" → `py screen.py suggest semiconductor momentum`
- "사용 가능한 테마 목록" → `py screen.py suggest`
- 지원 테마: quantum, ai, semiconductor, ev, biotech, defense, cloud, fintech, energy, clean, healthcare, consumer, crypto, space, robotics

결과는 "추천"이 아니라 "후보 정렬" — 상위는 기술/펀더멘털 심층분석으로 검증 안내.
발굴 기준은 종목발굴_기준.md 참고.

### ⚠️ screen.py 결과 인용 원칙 (환각 차단)
screen.py JSON에 **실제로 포함된 필드**만 표·문장에 쓴다:
`price, rsi14, ma20, ma50, pos52, fiftyTwoWeekHigh, fiftyTwoWeekLow, marketCap,
priceToSales (P/S), revenueGrowth (소수 비율), forwardPE, trailingPE, beta, trend, score, reasons`

**절대 지어내지 말 것 (JSON에 없는 항목):**
- 매출 금액("2024년 매출 $38.9M")·달러 성장액 (revenueGrowth는 비율만)
- 파트너십·고객사 이름 (Microsoft, Oracle, BMW 등)
- 기술방식 설명 (trapped ion, superconducting 등)
- 시장점유율·회사 사업 설명
- 여러 종목에 동일 문장 복붙 = 날조

null·없는 값은 "N/A" 또는 "데이터 미제공" 표기. 정성 분석이 필요하면
`py stock.py TICKER` 또는 sec.py로 별도 확인하거나 "확인 필요"로 명시.
