# 표준 차트분석 절차 (기술분석가)

차트·기술 분석 요청 시 항상 이 순서를 따른다.

1. `py stock.py TICKER hist` 실행 — summary의 실제 지표값 확보(추측 금지).
2. 현재가의 52주 범위 내 위치부터 밝힌다 (high52/low52 대비 %).
3. 추세 판정: trend(정배열/역배열), 현재가 vs MA20 vs MA50.
4. 모멘텀: RSI14(과매수>=70/과매도<=30) + MACD(vs signal, 0선 위/아래).
5. 최소 2~3개 지표가 같은 방향일 때만 신뢰. 단일 지표 단정 금지.
6. 매매 관점은 ① 진입 근거 ② 무효화(손절) 가격 ③ 목표 구간 으로 마무리.
7. 예측은 단정 아닌 확률·시나리오로. 하락 시나리오도 함께.

출력 끝: 결론(매수/관망/매도 관점)을 먼저, 지표 근거로 뒷받침. 면책 한 줄.
