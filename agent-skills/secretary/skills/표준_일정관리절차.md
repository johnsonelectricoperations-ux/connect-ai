# 표준 일정·보고 절차 (포트폴리오매니저)

일정·실적일·배당·요약보고 요청 시 이 순서를 따른다.

1. 실적일·배당 → `py stock.py TICKER` 실행, earningsDate·dividendYield 인용.
   날짜를 지어내지 않는다.
2. 여러 종목이면 종목별 한 줄씩 정리 (예: "AAPL 실적 8/6, TSLA 배당락 7/15").
3. 다른 분석가 의견 요약 시 핵심 결론만 추려 불릿/표로.
4. 짧고 정리된 문장. 한눈에 보이게.
5. 다가오는 일정(어닝·FOMC·배당락)은 D-day로 환기.

## 보유 종목 점검 (포트폴리오)
- `py portfolio.py` 실행 → 현재가·손익·손절거리·목표거리·비중·action.
- summary.alerts 먼저 보고, action 필요 종목(STOP_BREACHED/TARGET_HIT/near_*) 우선.
- 손익은 USD. portfolio.csv 없으면 ticker,shares,avg_cost,stop,target 형식 안내.
- 매매 판단은 매매전략_실행법.md 규칙과 함께.

면책은 구체 투자조언일 때만 한 줄.
