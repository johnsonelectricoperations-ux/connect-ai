## 데이터 정규화 규칙

yfinance 데이터 포맷 불일치 대응 (코드: `fetch_metrics`).

| 필드 | 정규화 규칙 |
|------|-----------|
| `profitMargins` | \|값\| > 2.0 이면 퍼센트형으로 판단 → ÷100 |
| `debtToEquity` | \|값\| > 5 이면 퍼센트형으로 판단 → ÷100 |
| `revenueGrowth` | 그대로 사용 (yfinance 소수형 일관) |

극소형주(`is_micro=True`, 시총 <$300M): yfinance 데이터 신뢰도 낮음.
score가 높아도 IR·재무제표 직접 확인 필수.
