## 추가 요청 사항

### 📥 외부 정보 수집 → 지식 자동 적재 (신규 도구 2종)

> **컨셉**: 기존 stock.py/sec.py와 동일한 패턴 — 독립 Python 프로그램이 같은 PC에서
> 웹(유튜브·뉴스)에 접속 → 정보 수집 → MD로 정리 → brain 폴더에 저장 → 다음 분석 때
> 자동 컨텍스트로 인식. 시스템 본체(확장)는 안 건드림(터미널/자율 실행). 채팅에서
> 부르려면 그때만 forcedArgs 라우팅 추가.

**저장 위치(공통)**: `10_Wiki/투자지식/_자동수집/`  (직접 쓴 지식과 분리)
**파일명 규칙**: `YYYY-MM-DD_소스_주제.md`  (예: `2026-06-05_IONQ_뉴스.md`)
**공통 원칙**: 각 MD 상단에 원본 URL·수집일시 명시 / 중복 ID 캐시로 재저장 방지 / 출처 표기로 날조 차단

#### ① `youtube_to_brain.py` — 유튜브 영상 내용 → 지식
- 채널 ID 또는 영상 URL 입력
- YouTube Data API(무료 키)로 영상 메타 + `youtube-transcript-api`(무료, 키 X)로 자막 추출
- 9B로 투자 핵심만 요약 → `_자동수집/`에 .md 저장
- 자막 없는 영상은 skip + 경고
- 필요 패키지: `pip install youtube-transcript-api google-api-python-client`
- 제한: 영어 대형채널(CNBC 등) 자막 양호, 한국 소형채널 자동자막 품질 편차

#### ② `news.py` — 뉴스/RSS 수집 → 지식
- 티커/키워드 입력 → 무료 RSS에서 최신 뉴스 수집 → 제목·날짜·요약·링크 정리
- 소스(ToS 안전): Yahoo Finance RSS, CNBC/Reuters RSS, SEC EDGAR RSS
- `py news.py IONQ` → 최신 5~10개 → `_자동수집/`에 .md 저장
- 외부 라이브러리 최소화(stdlib urllib + feedparser 정도)
