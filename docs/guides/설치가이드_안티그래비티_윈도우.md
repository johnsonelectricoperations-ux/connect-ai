# Connect AI 설치 가이드 (Antigravity · Windows · AMD GPU)

> 이 문서는 **Windows + AMD Radeon RX 7600 + RAM 32GB** 환경에서
> Google Antigravity로 Connect AI를 처음 설치하는 분을 위한 단계별 안내서입니다.
> 위에서부터 순서대로 하나씩 따라 하세요. 한 단계가 끝나야 다음 단계로 갑니다.

---

## 전체 그림 먼저 보기

설치할 프로그램은 4개입니다. 각자 역할이 다릅니다.

```
┌─────────────────────────────────────────────────┐
│  Antigravity (그릇 · IDE)                         │
│   ┌───────────────────────────────────────────┐  │
│   │  Connect AI 확장 (프로그램 본체)            │  │
│   └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
            ↑ 명령                    ↑ AI 두뇌
            │                         │
       (내가 채팅)            LM Studio (AI 모델 실행)

  + Node.js (Connect AI를 설치 파일로 빌드하는 도구)
  + Git (선택 · 지식 자동 백업용)
```

| 프로그램 | 역할 | 필수? |
|---|---|---|
| **Antigravity** | Connect AI가 실행되는 코드 편집기 | ✅ 필수 |
| **Node.js** | 소스코드를 설치 가능한 파일로 빌드 | ✅ 필수 |
| **LM Studio** | 내 PC에서 AI 모델을 돌리는 엔진 | ✅ 필수 |
| **Git** | 지식베이스 GitHub 자동 백업 | 🔵 선택 |

---

## STEP 1 — Antigravity 설치

1. 브라우저에서 **antigravity.google** 접속
2. Windows용 설치 파일 다운로드 후 실행
3. 설치 완료되면 한 번 실행해서 정상적으로 켜지는지 확인
4. 구글 계정 로그인 (안티그래비티 자체 AI 기능은 나중에 안 써도 됨)

> 💡 Antigravity는 VS Code를 기반으로 만든 IDE라, 화면 구성이 VS Code와 거의 같습니다.
> 인터넷에서 "VS Code 사용법"을 찾아봐도 그대로 적용됩니다.

✅ **확인:** Antigravity 창이 정상적으로 열리면 STEP 1 완료.

---

## STEP 2 — Node.js 설치

소스코드를 실제 작동하는 확장 파일(.vsix)로 만들려면 필요합니다.

1. 브라우저에서 **nodejs.org** 접속
2. **LTS** 버전(왼쪽 초록 버튼) 다운로드 후 실행
3. 설치 중 옵션은 전부 기본값으로 [Next] 진행
4. 설치 후 확인:
   - 키보드 `Win + R` → `cmd` 입력 → 엔터 (명령 프롬프트 열림)
   - 아래 두 줄을 한 줄씩 입력:
     ```
     node --version
     npm --version
     ```
   - `v22.x.x` 와 `10.x.x` 같은 숫자가 나오면 성공

✅ **확인:** 버전 숫자가 나오면 STEP 2 완료.

---

## STEP 3 — LM Studio 설치 + AI 모델 받기 (가장 중요)

Connect AI를 움직이는 **AI 두뇌**입니다. 사장님 GPU가 AMD라서 LM Studio를 씁니다.
(LM Studio는 AMD GPU를 Vulkan 기술로 자동 가속합니다.)

### 3-1. 설치
1. 브라우저에서 **lmstudio.ai** 접속
2. Windows용 다운로드 후 설치·실행

### 3-2. AI 모델 다운로드
사장님 사양(VRAM 8GB + RAM 32GB)에 맞는 추천 모델:

| 추천 | 모델 검색어 | 크기 | 특징 |
|---|---|---|---|
| ⭐ 1순위 | `gemma 3 12b` | ~7GB | 균형 최고, 한국어 자연스러움 |
| ⭐ 1순위 | `qwen2.5 7b instruct` | ~5GB | 빠름, GPU에 딱 맞음 |
| 도전 | `qwen2.5 14b` | ~9GB | 더 똑똑하지만 약간 느림 |

1. LM Studio 왼쪽 **돋보기(🔍 Search)** 아이콘 클릭
2. 위 검색어 중 하나 입력 (처음엔 `gemma 3 12b` 추천)
3. `Q4` 라고 표시된 버전 다운로드 (용량 대비 성능 균형이 좋음)

### 3-3. 서버 켜기 (이게 핵심)
1. LM Studio 왼쪽 **`>_` Developer** 탭(개발자 탭) 클릭
2. 위쪽에서 다운받은 모델 선택
3. **Start Server** 버튼 클릭
4. 주소가 `http://127.0.0.1:1234` 처럼 표시되면 성공 (포트 번호 기억해두기)

> ⚠️ Connect AI를 쓸 때는 **LM Studio의 이 서버가 항상 켜져 있어야** 합니다.
> 서버를 끄면 AI가 대답하지 못합니다.

✅ **확인:** "Server running" 표시가 뜨면 STEP 3 완료.

---

## STEP 4 — 소스코드 빌드 (Connect AI 설치 파일 만들기)

이제 받은 소스코드를 Antigravity에서 열고 빌드합니다.

1. **Antigravity 실행** → 상단 메뉴 `File` → `Open Folder`
2. 받은 **connect-ai 폴더** 선택해서 열기
3. 상단 메뉴 `Terminal` → `New Terminal` (아래쪽에 터미널 창 열림)
4. 터미널에 아래 명령을 한 줄씩 입력:

   ```
   npm install
   ```
   (필요한 부품 다운로드 — 1~2분 소요)

   ```
   npm run compile
   ```
   (소스코드 빌드 — `out/extension.js` 생성됨)

   ```
   npx vsce package
   ```
   (설치 파일 .vsix 생성 — 처음엔 vsce 설치 여부를 물으면 `y` 입력)

5. 폴더 안에 **`connect-ai-lab-2.89.157.vsix`** 같은 파일이 생기면 성공

✅ **확인:** `.vsix` 파일이 만들어지면 STEP 4 완료.

---

## STEP 5 — Connect AI 확장 설치

1. Antigravity에서 `Ctrl + Shift + P` (명령 팔레트 열림)
2. `Install from VSIX` 입력 후 선택
3. STEP 4에서 만든 `.vsix` 파일 선택
4. 설치 완료 후 Antigravity 재시작 (안내가 뜨면 [Reload])

✅ **확인:** 왼쪽 사이드바에 Connect AI 아이콘이 생기면 STEP 5 완료.

---

## STEP 6 — Connect AI 첫 설정 & 실행

1. 왼쪽 사이드바의 **Connect AI 아이콘** 클릭 → 채팅창 열림
2. 채팅창의 **⚙️ 설정**에서 AI 엔진 연결:
   - 엔진: **LM Studio** 선택
   - 주소: STEP 3에서 본 주소 (예: `http://127.0.0.1:1234`)
   - 모델: 자동 감지되면 그대로, 아니면 받은 모델 선택
3. 채팅창에 인사 한번 보내보기:
   ```
   안녕? 잘 작동하는지 테스트야.
   ```
4. AI가 한국어로 답하면 **설치 완전 성공!** 🎉

## 자주 막히는 곳 (문제 해결)

| 증상 | 원인 | 해결 |
|---|---|---|
| AI가 답을 안 함 | LM Studio 서버 꺼짐 | LM Studio Developer 탭 → Start Server 재확인 |
| `npm` 명령어 안 먹힘 | Node.js 미설치/재시작 필요 | PC 재부팅 후 다시 시도 |
| `vsce` 오류 | 설치 안 됨 | `npm install -g @vscode/vsce` 입력 후 재시도 |
| 모델이 너무 느림 | 모델이 큼 | 더 작은 모델(qwen 7b)로 교체 |
| 한국어가 어색함 | 모델 특성 | gemma 3 또는 qwen 계열 추천 |
