# 방산(Defense) 섹터 심화 (록히드·레이시온·노스롭·보잉)

> 펀더멘털·매크로 공용 지식. 방산 테마 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인.

## 1. 섹터 성격

- **정부 계약 기반**: 매출의 대부분이 미 국방부(DoD)·동맹국 정부 계약.
  → 경기 방어적, 민간 경기와 상관관계 낮음.
- 장기 계약·안정적 현금흐름 → 배당 지속성 높음.
- 지정학 긴장·전쟁·방산예산 증가 시 주가 모멘텀.

## 2. 주요 종목 성격

| 종목 | 특징 |
|------|------|
| LMT (록히드마틴) | F-35 전투기·미사일 방어. 안정 계약, 고마진 |
| RTX (레이시온) | 패트리엇 미사일·항공부품. 방산+민항 혼합 |
| NOC (노스롭) | B-21 스텔스폭격기·위성·사이버. 성장성 |
| GD (제너럴다이나믹스) | 스탈링거·함정·Gulfstream 항공기 |
| BA (보잉) | 방산+민항(737). 민항 품질 문제·현금흐름 부진이 발목 |
| KTOS | 드론·무인기 소형주. 성장성 높으나 소형주 변동성 |

## 3. 핵심 점검 지표

1. **수주잔고(Backlog)**: 미래 매출의 가시성. 방산 분석의 핵심 지표(도구 밖 → IR 확인).
2. **마진 추이**: 고정가 계약에서 원가 초과 시 마진 훼손.
3. **배당·자사주**: 안정적 현금흐름 지표.
4. **PER**: 방산 대형주는 PER 15~22 범위가 일반적.

## 4. 모멘텀·리스크 요인

- **모멘텀**: 국방예산 증가, NATO 방위비 상향, 분쟁 지역 확대, 드론·사이버 수요.
- **리스크**: 예산 삭감(연방 부채 협상), 프로그램 취소·지연, 보잉형 품질 이슈.
- **수출 규제**: 무기 수출 승인·규제가 해외 매출에 영향.

## 5. 데이터 출처 원칙

- 수주잔고·계약 세부는 도구 밖 → "공식 실적발표·IR 확인 권장".
- PER·마진·배당수익률은 `stock.py` JSON만 인용.
- 지정학 이벤트를 근거로 "주가 오를 것"이라 단정하지 않는다.
