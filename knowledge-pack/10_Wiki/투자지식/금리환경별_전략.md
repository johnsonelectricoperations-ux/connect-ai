# 금리 환경별 자산 전략 (인상·동결·인하 국면 대응)

> 매크로분석가 전용 지식. 금리 국면이 어떤 자산·섹터에 유리한지 판단.
> 현재 금리·국면은 `macro.py`(미 10년물·기준금리·달러)로 확인.

## 1. 금리가 주가를 움직이는 원리

- 금리↑ → 미래 현금흐름의 할인율↑ → **먼 미래 이익에 의존하는 성장주가 더 타격**.
- 금리↑ → 무위험 채권 수익률↑ → 주식의 상대 매력↓.
- 금리↓ → 유동성 확대 → 위험자산(성장주·소형주)에 우호.

## 2. 국면별 유불리 (요약표)

| 국면 | 유리한 자산 | 불리한 자산 | 핵심 |
|------|------------|------------|------|
| **금리 인상기** | 가치주·금융·에너지·단기채 | 고PER 성장주·장기채·리츠 | 현금흐름 가까운 종목 |
| **금리 정점·동결** | 우량 성장주·배당주 | — | 변동성 축소, 옥석 가리기 |
| **금리 인하기** | 성장주·소형주·리츠·장기채 | 현금·단기채 | 유동성 수혜 |
| **인하 후 침체** | 필수소비재·헬스케어·금 | 경기민감·소형주 | 방어 우선 |

## 3. 핵심 지표 읽기 (macro.py)

- **미 10년물 국채금리**: 성장주 밸류에이션의 기준. 급등 시 테크 약세 압력.
- **장단기 금리차(10년-2년)**: 역전(음수)은 침체 경고 신호로 통용.
- **달러 인덱스(DXY)**: 달러 강세 → 신흥국·원자재·다국적 기업 실적 부담.
- **기준금리 방향**: FOMC 점도표·발언이 시장 기대를 좌우.

## 4. 실전 적용 원칙

- 금리 급등 구간에서 고PSR 종목(양자·초기 테마) 신규 진입은 **비중 축소**.
- 인하 기대가 형성되면 성장주 선반영이 빠르게 일어남 → 너무 늦게 따라가지 말 것.
- "금리 하나로 모든 걸 설명하지 말 것" — 개별 실적·산업 사이클이 우선할 때도 많다.
- 매크로는 **방향·바람**이고, 종목 선택은 **펀더멘털**이다. 둘을 분리해 판단.

## 5. 데이터 출처 원칙

- 금리·달러·장단기차 수치는 `<run_command>py macro.py</run_command>` 결과만 인용.
- FOMC 일정·점도표 세부는 도구 밖 → "최신 FOMC 확인 권장"으로 안내, 지어내지 않음.
- 국면 판단이 애매하면 "혼조"로 명시하고 단정하지 않는다.
