# 전기차(EV) 섹터 심화 (테슬라·리비안·니오·충전 인프라)

> 펀더멘털·매크로 공용 지식. EV 테마 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인. 아래는 산업 구조·사이클·리스크 프레임.

## 1. 섹터 성격

- 자동차 + 에너지 + 소프트웨어의 교차점. **성숙 자동차 산업의 밸류가 아닌
  성장 기술주로 보는 시각과의 괴리**가 변동성 원천.
- 초기 순수 EV 기업(TSLA·RIVN·LCID)은 고자본 소모, 흑자 여부가 관건.
- 중국 EV(NIO·XPEV·LI)는 지정학·보조금 변수 크다.

## 2. 종목 성격 (개요)

| 종목 | 특징 |
|------|------|
| TSLA | 순수 EV 1위, 자율주행·에너지·FSD 수익화가 차별점. 고마진 vs 가격경쟁 딜레마 |
| RIVN | 픽업·SUV 특화, 아마존 상업용 계약. 대규모 적자, 현금 소진 속도가 핵심 |
| LCID | 프리미엄 고효율, 낮은 생산량. 유동성 위험 높음 |
| NIO/XPEV/LI | 중국 시장 내수, 보조금 의존, 미중 무역·상장폐지 리스크 |
| GM/F | 레거시 전환. EV는 적자지만 내연기관 현금흐름이 완충 |
| CHPT/BLNK | 충전 인프라. 매출 있으나 대부분 적자, 보조금·정책 의존 |

## 3. 핵심 점검 지표

1. **인도량(Deliveries)**: 실적 대리 지표. 분기 인도량 추이가 성장 판단의 핵심.
2. **매출성장률(`revenueGrowth`)·마진**: 생산 규모화로 마진이 개선되는가.
3. **현금·소진 속도**: 순수 EV 스타트업은 증자 위험 → `sec.py`로 공시 확인.
4. **P/S(`priceToSales`)**: 적자 기업은 PER 무의미 → P/S + 성장률 세트.

## 4. 구조적 리스크

- **가격 전쟁**: 테슬라 가격 인하 → 경쟁사·마진 압박 전이.
- **보조금·정책**: IRA·세액공제 변동, 중국 보조금 축소 → 수요 직결.
- **인프라 부족**: 충전망 미비가 대중화 속도를 제한.
- **배터리 소재·공급망**: 리튬·코발트 가격, 중국 공급 의존.

## 5. 데이터 출처 원칙

- 인도량·공장 생산능력은 도구 밖 → "공식 실적 발표·IR 확인 권장", 지어내지 않는다.
- 재무·마진·P/S는 `stock.py` JSON만 인용. 중국 EV는 상장폐지 리스크 발생 시 sec.py 참고.
