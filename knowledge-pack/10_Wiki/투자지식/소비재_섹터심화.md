# 소비재 섹터 심화 (아마존·코스트코·나이키·스타벅스·필수vs임의)

> 펀더멘털·매크로 공용 지식. 소비재 섹터 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인.

## 1. 필수소비재 vs 임의소비재 구분 (핵심)

| 구분 | 성격 | 대표 | 경기와의 관계 |
|------|------|------|------------|
| **필수(Staples)** | 음식·생필품·약국 | WMT, COST, PG, KO | 경기 방어, 안정 |
| **임의(Discretionary)** | 의류·음식점·전자 | AMZN, NKE, SBUX, MCD, HD | 경기 민감 |

> 같은 "소비재"라도 경기 국면별 대응이 반대다. 반드시 구분해서 판단.

## 2. 주요 종목 성격

| 종목 | 특징 |
|------|------|
| AMZN | e커머스+AWS 혼합. 리테일은 박마진, AWS 고마진이 이익 주도 |
| COST (코스트코) | 멤버십 기반, 박마진·고회전. 갱신율 90%+가 해자 |
| WMT | 오프라인 지배력, 디지털 전환 중. 안정 방어주 |
| TGT | 임의소비재 비중 높아 경기 민감. 재고·마진 변동성 |
| HD/LOW | 주택경기 연동. 금리·주택시장 민감 |
| NKE | 브랜드·프리미엄. 중국 익스포저, 재고 사이클 |
| SBUX/MCD/YUM | 음식점 체인. 소비자 지출·임금·원재료 비용 삼중 변수 |

## 3. 핵심 점검 지표

1. **동일매장매출(SSS, Same-Store Sales)**: 기존 점포 성장 → 도구 밖, IR 확인.
2. **마진 추이**: 원재료·임금 인플레이션이 마진 압박.
3. **재고 회전율**: 재고 증가는 할인 압박·마진 훼손 선행 신호.
4. **PER**: 필수소비재는 낮은 PER(12~20), 임의소비재는 성장성에 따라.

## 4. 구조적 리스크

- **소비 위축**: 경기 침체·고금리 → 임의소비재 직격.
- **임금·원재료 인플레이션**: 음식점·소매의 마진 압박.
- **아마존 효과**: e커머스 확장이 오프라인 소매 지속 잠식.
- **중국 노출**: NKE 등 중국 매출 비중 높은 종목 → 지정학·소비 둔화 리스크.

## 5. 데이터 출처 원칙

- SSS·멤버십 갱신율 등은 도구 밖 → "공식 실적발표 확인 권장".
- PER·마진·성장률은 `stock.py` JSON만 인용.
- 필수/임의 구분을 `sector` 필드로 확인 후 적합한 밸류 잣대 적용.
