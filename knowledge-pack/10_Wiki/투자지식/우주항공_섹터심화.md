# 우주항공(Space) 섹터 심화 (로켓랩·AST스페이스모바일·스페이스X 연관주)

> 리서처·펀더멘털 공용 지식. 우주 테마 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인.

## 1. 섹터 성격

- **초기·고위험·테마**: 양자컴퓨터와 유사하게 대부분 적자, 실적보다 기대로 움직임.
- 정부(NASA·DoD·SpaceX 상업 계약) + 민간 위성통신 수요가 성장 동력.
- 소형주 多 → 유동성 낮고 변동성 극단적.

## 2. 비즈니스 모델 분류

| 모델 | 대표 | 특징 |
|------|------|------|
| 발사체(Launch) | RKLB (로켓랩) | 소형 위성 발사, 상업화 진행 중 |
| 위성통신(Space Mobile) | ASTS | 위성 직접 스마트폰 연결. 아직 초기, 고위험 |
| 달·탐사 서비스 | LUNR | NASA CLPS 계약. 초기·소형주 |
| 위성 이미지 | MNTS (모멘투스), SATL | 소형주·고위험 |
| 위성·방산 겸업 | LMT, NOC, KTOS | 방산이 주력, 우주는 부수익 |

## 3. 핵심 점검 지표

1. **계약·수주(Backlog)**: 정부·상업 계약 확보 규모 → 도구 밖, IR 확인.
2. **발사 성공률**: 로켓랩 등은 실패 시 주가 충격.
3. **현금 소진**: 적자+소형주 = 증자 위험 상시. `sec.py` 8-K 모니터.
4. **P/S + 매출성장률**: PER 무의미 → P/S와 성장률 세트.

## 4. 구조적 리스크

- **기술 실패·발사 실패**: 단 한 번의 실패로 주가 급락 가능.
- **스페이스X 경쟁**: 비상장이지만 팰컨9·스타십이 발사 비용을 급락시켜 경쟁 압박.
- **규제·주파수 허가**: 위성통신은 FCC 허가 지연이 리스크.
- **소형주 유동성**: 시총 수억~수십억 달러 → 대량 매수/매도 시 가격 충격.

## 5. 데이터 출처 원칙

- 발사 일정·계약 규모·기술 진척은 도구 밖 → "공식 IR·뉴스 확인 권장".
- 재무는 `stock.py` JSON만. 소형주는 데이터 불완전할 수 있음 → null 필드 많을 때
  "데이터 미제공" 표기하고 추정 금지.
- "우주 산업의 미래"를 기정사실처럼 쓰지 말 것 — 상용화 시점은 불확실.
