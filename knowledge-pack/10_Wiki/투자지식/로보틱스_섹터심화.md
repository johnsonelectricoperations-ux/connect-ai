# 로보틱스(Robotics) 섹터 심화 (수술로봇·산업로봇·자율화·비전)

> 펀더멘털·리서처 공용 지식. 로보틱스 테마 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인.

## 1. 섹터 성격

- **이종(異種) 집합체**: 수술로봇(의료)·산업로봇(제조)·비전시스템·반도체(NXP·NVDA)가
  묶여 있다 → 종목별 성격이 완전히 다름. 하나의 잣대 적용 불가.
- AI·자동화 트렌드의 물리적 구현 → 중장기 성장 테마.
- 일부는 흑자 안정(ISRG), 일부는 성장초기 적자(IRBT).

## 2. 세그먼트별 분류

| 세그먼트 | 대표 | 특징 |
|----------|------|------|
| 수술로봇 | ISRG (다빈치) | 강력한 설치 기반·소모품 잠금. 고마진·흑자 |
| 산업로봇·자동화 | ABB, FANUC, TER | 제조 설비투자 사이클에 연동 |
| 반도체(로봇 두뇌) | NXPI, NVDA | 엣지 AI·임베디드, 넓은 응용 |
| 테스트·자동화 장비 | TER (테러다인), ONTO, BRKS | 반도체·전자 제조 테스트 |
| 비전 시스템 | CGNX (코그넥스) | 머신비전 독점적 위치, 경기 민감 |
| 소비자 로봇 | IRBT (아이로봇) | 청소로봇, 아마존 M&A 무산 후 약화 |

## 3. 핵심 점검 지표

1. **ISRG류**: 설치 대수 성장, 소모품 매출 비율(반복매출), 수술 건수.
2. **산업로봇(ABB·FANUC)**: 제조업 PMI·설비투자(Capex) 사이클과 동행.
3. **반도체 포함 종목(NVDA·NXPI)**: AI반도체_섹터심화.md와 겹침 — 주력 사업 확인 후 판단.
4. **소형 순수 플레이**: P/S + 성장률, 현금 소진, 증자 위험.

## 4. 구조적 리스크

- **설비투자 사이클**: 제조업 경기 둔화 → 산업로봇 주문 급감.
- **중국 경쟁**: 저가 산업로봇 확산 → 마진 압박.
- **자율주행 연계 불확실성**: 로봇+자율주행 시너지 기대가 과도하게 반영된 종목 주의.
- **소형주 유동성**: IRBT·소형 로봇주는 변동성·유동성 위험.

## 5. 데이터 출처 원칙

- 설치 대수·주문 잔고·소모품 비율은 도구 밖 → "공식 실적발표 확인 권장".
- 재무·마진·PER은 `stock.py` JSON만 인용.
- "로봇이 모든 걸 바꾼다"는 식의 테마 과장 자제 — 실제 매출·이익 증거 기반으로 분석.
