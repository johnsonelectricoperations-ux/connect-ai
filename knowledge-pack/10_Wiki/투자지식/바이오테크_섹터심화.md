# 바이오테크 섹터 심화 (임상·FDA·유전자편집·mRNA)

> 펀더멘털·리서처 공용 지식. 바이오테크 분석 시 따른다.
> 임상 데이터·FDA 일정은 도구 범위 밖 — 공식 IR·SEC 공시 확인 권장.

## 1. 섹터 성격

- **이벤트 드리븐(Event-Driven)**: 임상 결과·FDA 결정 하루에 ±50% 급변 흔함.
- 대부분 적자, PER 무의미 → 파이프라인 가치·현금 보유·흑자전환 시점으로 평가.
- 대형 제약(J&J·화이자)과 소형 바이오테크를 완전히 다른 기준으로 봐야 한다.

## 2. 임상 단계 이해 (필수)

| 단계 | 목적 | 성공률 |
|------|------|--------|
| 1상 | 안전성·용량 | ~65% |
| 2상 | 효능·안전성 | ~40% |
| 3상 | 대규모 효능 입증 | ~60% |
| FDA 심사 | 허가 결정 | 3상 통과 후 ~85% |

> 1상~최종 허가까지 전체 확률 약 10~15% — "파이프라인 있다"가 곧 가치가 아님.

## 3. 주요 종목 성격

| 종목 | 특징 |
|------|------|
| MRNA/BNTX | mRNA 플랫폼. 코로나 이후 파이프라인 다각화 중, 수익성이 관건 |
| REGN/VRTX | 상업화 성공·흑자, 상대적 안정적. 전통 바이오 밸류 |
| BIIB | 알츠하이머 등 신경계 집중. 블록버스터 허가 여부가 주가 좌우 |
| CRSP/EDIT/NTLA/BEAM | 유전자 편집(CRISPR 등) 초기. 매출 미미, 파이프라인만 |
| ILMN | 유전체 분석 장비. 테크 성격, 적자 탈출 여부 |

## 4. 핵심 분석 포인트

1. **현금 보유·소진속도(Burn Rate)**: 다음 임상까지 버틸 자금인가.
2. **파이프라인 단계·개수**: 분산도(한 물질에만 의존 vs 복수 파이프라인).
3. **특허 만료**: 블록버스터 특허 만료 → 제네릭 진입 → 매출 급감.
4. **상업화된 제품 있는가**: 매출 있는 바이오와 없는 바이오는 리스크가 다르다.

## 5. 구조적 리스크

- **임상 실패**: 3상 실패 = 주가 50~80% 급락 가능.
- **FDA 결정**: 허가 지연·CRL(거부 서한) → 급락.
- **희석 위험**: 잦은 증자(유상증자) → 주주가치 희석. `sec.py`로 8-K 공시 모니터.
- **인수합병 변수**: 대형 제약의 M&A 타깃 → 프리미엄 급등 가능(양날의 검).

## 6. 데이터 출처 원칙

- 임상 단계·FDA 일정·파이프라인 세부는 도구 밖 → 지어내지 말고 "공식 IR·SEC 확인".
- 재무(현금·마진·성장률)는 `stock.py` JSON. 공시·8-K는 `sec.py`.
- "임상 결과가 좋을 것"이라는 예측은 하지 않는다 — 데이터 나오기 전엔 불확실성만 표시.
