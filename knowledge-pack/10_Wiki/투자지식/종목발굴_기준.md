# 종목 발굴 기준 (스크리닝·후보 선별)

> 리서처·CIO 공용. 새 종목을 발굴·추천할 때 따른다.
> 객관 랭킹은 `py screen.py value|momentum`, 검증은 stock.py/sec.py로.

## 1. 발굴의 두 가지 경로

### 경로 A: 내가 후보 입력 (watchlist.txt)
1. `watchlist.txt`에 관심 티커를 직접 입력.
2. `py screen.py value` 또는 `py screen.py momentum` 으로 랭킹.
3. 상위 후보를 기술/펀더멘털/리스크 심층분석.

### 경로 B: 시스템이 테마 유니버스에서 자동 발굴 (suggest 모드)
1. 테마를 지정하면 내장 유니버스에서 자동 스크리닝:
   - `py screen.py suggest quantum` → 양자컴퓨터 종목 발굴
   - `py screen.py suggest ai momentum` → AI반도체 성장모멘텀 랭킹
   - `py screen.py suggest` → 사용 가능한 테마 목록 확인
2. 지원 테마: quantum, ai, semiconductor, ev, biotech, defense, cloud, fintech, energy, clean, healthcare, consumer, crypto, space, robotics
3. 상위 후보를 동일하게 심층검증.

**두 경로 병행 가능**: 테마 발굴로 후보를 찾고 → watchlist.txt에 추가 → 관리.

## 2. 두 가지 발굴 전략

### value (저평가·반등)
- 52주 저점 근접(낙폭 과대) + 과매도 RSI + 낮은 P/S.
- 논리: 과도하게 빠진 우량 후보의 평균회귀(반등) 노림.
- 함정: "싼 데는 이유가 있다" — 구조적 악재(적자 심화·소송)는 제외.

### momentum (성장 모멘텀)
- 정배열 추세 + 높은 매출성장 + 과열 아닌 RSI.
- 논리: 강한 추세·성장 지속 노림.
- 함정: 이미 많이 올라 기대 선반영. 과매수(RSI>75)는 진입 타이밍 주의.

## 3. 후보 검증 체크리스트 (상위 후보에 적용)

- [ ] 섹터 적정 잣대로 밸류에이션 (양자=P/S, 금융=PBR 등)
- [ ] forwardPE 음수면 적자 예상 — 현금소진·흑자전환 시점 확인(sec.py)
- [ ] 베타로 변동성 파악, 진입 시 비중·손절 계획(stock.py risk)
- [ ] 최근 공시·뉴스에 악재 없는지(sec.py / 검색)
- [ ] 거시 환경이 그 섹터에 우호적인지(macro.py)

## 4. 추천 시 출력 원칙

- "추천"은 ① 후보 ② 점수·근거 ③ 진입 시 손절·목표·비중 ④ 핵심 리스크를 함께.
- 단정("무조건 오른다") 금지. 확률·시나리오로.
- screen.py 결과는 "후보 정렬"임을 명시 — 자동 매수신호가 아니다.
- 최종 판단·책임은 사용자 본인 (면책).
