# 클라우드·SaaS 섹터 심화 (AWS·애저·구글·스노우플레이크·데이터독)

> 펀더멸·리서처 공용 지식. 클라우드·SaaS 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인.

## 1. 섹터 성격

- **반복매출(Recurring Revenue)**: 구독 기반 → 예측 가능한 현금흐름, 높은 마진.
- 고성장 SaaS는 적자여도 매출성장률·룰오브40(Rule of 40)으로 평가.
- 인프라(IaaS) vs 플랫폼(PaaS) vs 소프트웨어(SaaS) 레이어가 다르다.

## 2. 밸류에이션 지표 (SaaS 특화)

- **Rule of 40**: 매출성장률(%) + 영업이익률(%) ≥ 40이면 우량.
  (예: 성장률 30% + 마진 15% = 45 → 합격)
- **NRR(순매출유지율)**: 기존 고객에서 작년 대비 올해 매출 비율. 110% 이상 = 확장.
- **P/S**: 고성장 SaaS는 P/S 10~20배 정상, 성장 둔화 시 P/S 급격히 수축.

## 3. 주요 종목 성격

| 종목 | 특징 |
|------|------|
| AMZN/MSFT/GOOGL | 클라우드 빅3(AWS·Azure·GCP). 성장 둔화 주시 |
| CRM (세일즈포스) | CRM SaaS 대표주. 수익성·AI 통합 전략 |
| SNOW (스노우플레이크) | 데이터 클라우드. 소비 기반 과금 = 경기 민감. 적자 |
| DDOG (데이터독) | DevOps 모니터링. 높은 NRR, 고성장 |
| NET (클라우드플레어) | 엣지·보안·네트워크. 적자지만 성장 강함 |
| ZS (지스케일러) | 제로트러스트 보안. |
| MDB (몽고DB) | 개발자 데이터베이스. 소비 기반 |

## 4. 구조적 리스크

- **성장 둔화**: 고성장 → 보통 성장 전환 시 PER·PS 급격히 수축(멀티플 compression).
- **경쟁**: AWS·Azure·GCP가 자체 서비스로 SaaS 잠식.
- **소비 기반 과금 모델**: 경기 둔화 시 고객사가 사용량 줄이면 매출 즉각 영향(SNOW·DDOG).
- **AI 대체**: 생성형 AI가 일부 SaaS 기능을 대체할 수 있다는 우려.

## 5. 데이터 출처 원칙

- Rule of 40·NRR은 도구 밖 → "공식 실적발표 확인 권장", 추정 금지.
- 매출성장률·마진·P/S는 `stock.py` JSON만 인용.
- 성장 둔화 판단은 `revenueGrowth` 필드의 추세로만 — 도구에 없으면 "확인 필요".
