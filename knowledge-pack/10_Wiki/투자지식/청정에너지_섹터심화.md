# 청정에너지(Clean Energy) 섹터 심화 (태양광·풍력·수소·ESS)

> 매크로·펀더멘털 공용 지식. 청정에너지 테마 분석 시 따른다.
> 종목별 실수치는 stock.py로 확인.

## 1. 섹터 성격

- **정책 의존도 높음**: IRA(인플레이션감축법)·보조금·세액공제가 수익성을 좌우.
  정권 교체·정책 변화에 민감.
- 금리 상승기에 취약: 자본 집약적 사업 → 높은 금리 = 프로젝트 경제성 악화.
- 성장 스토리 강하지만 수익화 속도가 느림 → 고P/S·적자 많음.

## 2. 세그먼트 분류

| 세그먼트 | 대표 | 특징 |
|----------|------|------|
| 태양광(인버터·모듈) | ENPH, SEDG, FSLR | 인버터는 마진 좋지만 경쟁. FSLR은 제조 |
| 태양광 설치·금융 | RUN | 주택 태양광 리스. 금리 민감 |
| 유틸리티(재생에너지) | NEE, BEP, CWEN | 안정적 PPA 계약, 배당 |
| 수소·연료전지 | PLUG, BLDP | 대부분 적자, 상용화 멀음, 고변동 |
| 풍력·기타 | AES | 다각화 유틸리티 |

## 3. 핵심 점검 지표

1. **매출성장률·마진**: 설치 확대 → 마진 개선 추세인가.
2. **정책 노출**: IRA·인센티브가 실적에 얼마나 반영됐나.
3. **금리 민감도**: 프로젝트 파이낸싱 비용 — 금리 상승기 신규 프로젝트 수익성 악화.
4. **P/S**: 적자 기업 대부분 → P/S + 성장률로.

## 4. 구조적 리스크

- **정책 리스크**: 보조금 축소·세액공제 변경 → 사업 경제성 직격.
- **공급과잉**: 중국산 태양광 패널 저가 공세 → 미국 제조사 마진 압박.
- **금리**: 자본 집약적 → 금리 고점 구간에서 밸류에이션·프로젝트 수익성 동시 압박.
- **수소 상용화**: 아직 비싼 생산비용, 인프라 부족 → PLUG 같은 종목 상용화 시점 불확실.

## 5. 데이터 출처 원칙

- 정책·보조금 세부(IRA 세액공제 금액 등)는 도구 밖 → "최신 정책 확인 권장".
- 재무·마진·P/S는 `stock.py` JSON만 인용.
- 수소·연료전지 상용화 시점 단정 금지 — "불확실성 높음"으로 표현.
